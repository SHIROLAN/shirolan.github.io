## 📝 How to Customize

1. Edit `index.html` to update content (name, bio, projects)
2. Edit `styles.css` to change colors and styling
3. Commit and push changes - GitHub Pages will auto-deploy

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/SHIROLAN/shirolan.github.io.git
   ```

2. Make your changes locally

3. Commit and push:
   ```bash
   git add .
   git commit -m "Update portfolio"
   git push
   ```

4. Your site will be live at `https://shirolan.github.io` within minutes!
