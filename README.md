# Sumeet Chandankar — Portfolio

Built with **Vue 3 + Vite**. No external UI frameworks.

## Sections

- **Hero** — Particle canvas, text cycle, profile image
- **About** — Bio + skill chips
- **Projects** — 6 project cards with hover reveal
- **Experience** — Timeline
- **Contact** — Form with validation + social links
- **Footer**

## Commands

```bash
npm run dev      # dev server
npm run build    # production build
npm run preview  # preview build
```

## Tech

- Vue 3 (Composition API, `<script setup>`)
- Vite
- CSS variables + scoped styles
- IntersectionObserver for scroll reveal
- Canvas particle background (pauses on inactive tab)
- Custom cursor (disabled on touch devices)
- No jQuery, Bootstrap, Tailwind, or heavy libraries
